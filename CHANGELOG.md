# Changelog

Все значимые изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Changed
- Настройки приложения перемещены в стандартные папки конфигурации ОС:
  - Windows: `%APPDATA%\IvkExportTool\settings.json`
  - Linux/macOS: `~/.config/IvkExportTool/settings.json`
- Интегрирована библиотека [Config.Net](https://github.com/aloneguid/config) для управления настройками
- Удалена зависимость от `Microsoft.Extensions.Configuration.Json`
- Убрано копирование `appsettings.json` в CI/CD pipeline

### Removed
- Удалено неиспользуемое поле `Database` из настроек подключения

### Fixed
- Центрирование текста статуса в окне автоподключения

## [0.1.0] - 2025-10-29

### Added
- Стартовое окно с выбором способа подключения
- Автоподключение с перебором предустановленных учётных данных
- Шифрование credentials с использованием AES-256
- Окно ручного подключения к MySQL
- Главное окно с выбором БД и таблиц
- Экспорт выбранных таблиц в SQL-файл
- Сохранение параметров подключения
- Тристейтный чекбокс для массового выбора таблиц
- Фильтрация таблиц по имени
- Отображение прогресса экспорта
