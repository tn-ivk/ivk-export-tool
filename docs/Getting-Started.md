# Быстрый старт

Это руководство поможет вам начать работу с **IvkExportTool** за 5 минут.

## Предварительные требования

Перед началом убедитесь, что у вас есть:

- **MySQL Server** (версия 5.7 или выше)
- Доступ к базе данных (IP-адрес, порт, логин, пароль)
- Операционная система: Windows 10+, Linux (Ubuntu 20.04+), или macOS 10.15+

## Шаг 1: Установка

### Вариант A: Скачать готовое приложение (рекомендуется)

1. Перейдите на страницу [Releases](https://github.com/YOUR_USERNAME/ivk-export-tool/releases)
2. Скачайте последнюю версию для вашей платформы:
   - **Windows**: `IvkExportTool-win-x64.zip`
   - **Linux**: `IvkExportTool-linux-x64.tar.gz`
   - **macOS**: `IvkExportTool-osx-x64.tar.gz`
3. Распакуйте архив в удобную папку
4. Запустите исполняемый файл:
   - **Windows**: `IvkExportTool.Desktop.exe`
   - **Linux/macOS**: `./IvkExportTool.Desktop`

### Вариант B: Сборка из исходников

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/ivk-export-tool.git
cd ivk-export-tool

# Восстановить зависимости
dotnet restore

# Запустить приложение
dotnet run --project src/IvkExportTool.Desktop/IvkExportTool.Desktop.csproj
```

> **Примечание**: Для сборки из исходников требуется **.NET 10.0 SDK**. Установите его с [официального сайта](https://dotnet.microsoft.com/download).

## Шаг 2: Первое подключение к базе данных

После запуска приложения вы увидите окно подключения:

![Connection Window](images/connection-window.png)

1. **Введите данные подключения**:
   - **Хост**: IP-адрес или имя хоста MySQL сервера (например, `localhost` или `192.168.1.100`)
   - **Порт**: порт MySQL (по умолчанию `3306`)
   - **Логин**: имя пользователя MySQL (например, `root`)
   - **Пароль**: пароль пользователя

2. **Протестируйте подключение** (необязательно):
   - Нажмите кнопку **"Тест подключения"**
   - Убедитесь, что появилось сообщение об успешном подключении

3. **Подключитесь**:
   - Нажмите кнопку **"Подключиться"**

## Шаг 3: Выбор базы данных

После успешного подключения откроется главное окно:

![Main Window](images/main-window.png)

1. В выпадающем списке **"База данных"** выберите нужную базу данных
2. Приложение автоматически загрузит список таблиц с информацией:
   - Имя таблицы
   - Количество строк
   - Размер (в KB/MB/GB)
   - Тип движка (InnoDB, MyISAM и т.д.)

## Шаг 4: Выбор таблиц для экспорта

Выберите таблицы, которые хотите экспортировать:

- **Отдельные таблицы**: Поставьте галочки напротив нужных таблиц
- **Все таблицы**: Нажмите кнопку **"Выбрать все"** или используйте чекбокс в заголовке таблицы
- **Снять выбор**: Нажмите кнопку **"Снять выбор"**

### Фильтрация таблиц

Используйте поле поиска для быстрого поиска таблиц:

```
Введите часть имени таблицы → Список автоматически отфильтруется
```

## Шаг 5: Экспорт данных

1. Нажмите кнопку **"Экспортировать"**
2. В диалоге сохранения файла:
   - Выберите папку для сохранения
   - Имя файла будет предложено автоматически:
     - **Одна таблица**: `database_tablename_YYYYMMDD_HHMMSS.sql`
     - **Несколько таблиц**: `database_YYYYMMDD_HHMMSS.sql`
   - При необходимости измените имя файла
3. Нажмите **"Сохранить"**

### Что включает экспортированный SQL-файл?

Экспортированный файл содержит:

- **Структуру таблиц**: полные `CREATE TABLE` запросы
- **Данные таблиц**: `INSERT` запросы со всеми строками
- **Настройки кодировки**: корректная работа с UTF-8
- **Транзакции**: для безопасного импорта

## Шаг 6: Использование экспортированных данных

Для восстановления данных используйте MySQL клиент:

```bash
# Через командную строку
mysql -u username -p database_name < exported_file.sql

# Или через MySQL Workbench
# File → Run SQL Script → Выберите экспортированный файл
```

## Решение проблем

### Ошибка подключения к MySQL

**Проблема**: "Не удалось подключиться к серверу"

**Решения**:
1. Проверьте, что MySQL сервер запущен
2. Убедитесь, что хост и порт указаны правильно
3. Проверьте, что пользователь имеет права доступа
4. Убедитесь, что firewall не блокирует подключение

```sql
-- Предоставление прав пользователю (выполнить на сервере MySQL)
GRANT ALL PRIVILEGES ON *.* TO 'username'@'%' IDENTIFIED BY 'password';
FLUSH PRIVILEGES;
```

### Приложение не запускается на Linux

**Проблема**: "Permission denied"

**Решение**: Добавьте права на выполнение:

```bash
chmod +x IvkExportTool.Desktop
./IvkExportTool.Desktop
```

### Ошибка "Unable to load shared library 'libdl'"

**Проблема**: Отсутствуют системные библиотеки (Linux)

**Решение**: Установите необходимые зависимости:

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install -y libicu-dev libssl-dev

# Fedora/CentOS
sudo dnf install -y icu openssl-libs
```

### Таблицы не отображаются

**Проблема**: После выбора базы данных таблицы не загружаются

**Решение**:
1. Проверьте, что у пользователя есть права на чтение схемы БД
2. Убедитесь, что в базе данных есть таблицы
3. Попробуйте сменить базу данных и вернуться обратно
