# IvkExportTool Wiki

Добро пожаловать в документацию **IvkExportTool** — кроссплатформенного портабельного приложения для экспорта таблиц MySQL в SQL-файлы.

## Основные возможности

- 🔌 **Подключение к MySQL** — гибкая настройка подключения (IP, порт, логин, пароль)
- 📊 **Просмотр таблиц** — отображение списка баз данных и таблиц с информацией о размере и количестве строк
- ✅ **Выбор таблиц** — выборочный или полный экспорт таблиц
- 💾 **Экспорт в SQL** — создание SQL-файлов с полной структурой и данными
- 🔄 **Восстановление** — поддержка импорта экспортированных данных
- 🖥️ **Кроссплатформенность** — Windows, Linux, macOS
- 🎨 **Современный GUI** — интерфейс на Avalonia UI с Material Design 3

- **.NET 10.0** — современная платформа разработки
- **Avalonia UI 11.3.8** — кроссплатформенный GUI фреймворк

## Системные требования

### Для использования
- .NET 10.0 Runtime (для портабельной версии не требуется)
- MySQL Server 5.7+ (для подключения)
- Операционная система: Windows 10+, Linux (Ubuntu 20.04+), macOS 10.15+

### Для разработки
- .NET 10.0 SDK
- IDE: Visual Studio 2022, JetBrains Rider или VS Code
- Git
